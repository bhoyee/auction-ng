# Live monitor visual review

Screenshots at 360, 768, 1280, 1440 and 1920 pixels are generated by `tests/e2e/staff-live-monitor.spec.ts` against the actual admin production build. They exercise the shared shell, supplied LotVanta logo, protected-page rendering, pagination, chart and independent loading/error/empty behavior.

The browser harness stubs staff authentication, transport and API responses with synthetic review fixtures. Its 3,000 total is a layout example, not the actual demo's live inventory, and these screenshots are not evidence of an authenticated end-to-end login. API/Redis/real-gateway and isolated PostgreSQL tests cover the underlying data path separately. Local runtime uses real seeded application records, not these fixtures.

The approved reference is `../admin-live.png`. Keep the existing menu destinations, use the LotVanta image logo, and retain truthful unavailable states for telemetry that has not yet been instrumented. The disabled operational controls are unfinished and must not be represented as working.
