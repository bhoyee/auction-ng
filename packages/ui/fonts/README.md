# Schibsted Grotesk

The upright variable font is vendored from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/schibstedgrotesk) under the SIL Open Font License in `OFL.txt`. Admin loads it with `next/font/local`; mobile loads the same file with `expo-font`. The buyer website uses the local WOFF2 files described below. No external font request is required.

The buyer website uses official v7 WOFF2 subsets while retaining weights 400–900. The 35,148-byte common subset covers U+0020–007E, U+20A6 (Naira), U+2018/2019/201C/201D, U+2013/2014, U+2026, U+2212 and U+00B7. It is generated by the same Google Fonts stylesheet using its `text` parameter with those characters. Full Latin and Latin-extended subsets remain fallbacks for other supported names and text, before the generic fallback font. Unicode ranges prevent unnecessary fallback downloads.

The 17,700-byte common regular file is Google's instantiated weight-400 version of the same character set. It was retrieved from the stylesheet with explicit static weights and a WOFF2-capable, pre-variable-font browser user agent (Chrome 49). The original variable subset supplies weights 500–900.

`pnpm fonts:generate` embeds the smaller regular file in `web.css`, a shared stylesheet cached with the rest of the buyer CSS. This prioritizes body text without a separate critical font request. The additional regular asset trades a small increase in total font bytes for earlier readable text; heavier weights and other glyph subsets use cached local CSS asset URLs. There is no browser request to Google. `pnpm lint` checks that the generated stylesheet matches its source. Admin and Expo retain the original TTF and their existing loaders.

Sources: [Latin WOFF2](https://fonts.gstatic.com/s/schibstedgrotesk/v7/Jqz55SSPQuCQF3t8uOwiUL-taUTtap9Gayo.woff2), [Latin extended WOFF2](https://fonts.gstatic.com/s/schibstedgrotesk/v7/Jqz55SSPQuCQF3t8uOwiUL-taUTtap9Iayoxdg.woff2), [Google Fonts stylesheet](https://fonts.googleapis.com/css2?family=Schibsted+Grotesk:wght@400..900&display=swap).
